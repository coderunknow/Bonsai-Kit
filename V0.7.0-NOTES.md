# v0.7.0 audit notes

The streaming transport yields dictionaries: `delta` and `reasoning` carry `text`; the terminal `done` carries `message`, `usage`, `finish_reason`, timings, elapsed, TTFT and chunk count. Usage is supplied by the server's final SSE payload. A `StreamInterrupted` retains partial text and reports the number of chunks.

Capability states are exactly `supported`, `unsupported`, and `unknown`; `CapabilityMap.to_dict()` exposes `fields`, `evidence`, and `facts`. Doctor additionally uses PASS, FAIL, SKIP, UNKNOWN, and DEGRADED for checks. The four proxy classes are connection, unauthorized (401/403), remote, mid_stream, and stall (timeout).

The local UI is justified because it keeps the endpoint key server-side, works with local config/session files, and provides consistent settings while the remote tunnel remains model infrastructure rather than a local application.

Places existing code fights this slice: the existing CLI parser is intentionally large and defaults are layered; `ChatStream` owns socket cleanup and must not be duplicated by the proxy; capability facts are learned lazily, so unknown must remain visible rather than guessed.
